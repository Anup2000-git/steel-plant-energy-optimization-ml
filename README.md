# ⚙️ Optimization of Energy Consumption in Steel Manufacturing Plant using Machine Learning

This project focuses on reducing energy consumption and optimizing operations in a steel manufacturing plant using advanced data analytics and machine learning techniques. By identifying high-energy-consuming patterns and predicting future energy demand, the model helps in minimizing energy wastage and improving operational efficiency.

---

## 🧭 Project Objectives

- Analyze historical energy consumption data
- Identify patterns and correlations between production factors and energy usage
- Build a predictive ML model (XGBoost) to estimate energy consumption
- Provide insights to reduce energy costs and improve efficiency

---

## 🧠 Key Features

- 📊 Exploratory Data Analysis (EDA)
- ⚙️ Feature Engineering & Preprocessing
- 🔍 Model Building using XGBoost
- 📈 Performance Evaluation (R², MAE, RMSE)
- 🌐 Streamlit Dashboard for Visualization & Deployment
